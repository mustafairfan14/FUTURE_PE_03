# FUTURE_PE_03: AI SEO Blog & Content Cluster Generator for Business Websites

## Project Overview
This repository contains an end-to-end prompt engineering framework designed to plan, structure, and generate ranking-focused SEO content clusters and long-form pillar blogs for local businesses.

For this project, **Rambo Cafeteria** (Al Nakheel, Ajman, UAE) was selected to build a complete Local SEO strategy targeting high-intent food, dining, and delivery keywords.

## SEO Strategy & Architecture
* **Target Business:** Rambo Cafeteria (Al Nakheel, Ajman)
* **SEO Model:** Hub-and-Spoke (1 Pillar Page + 4 Supporting Cluster Articles)
* **Target Geographic Area:** Ajman / Sharjah Border / Al Nakheel, UAE
* **Primary Pillar Keyword:** `late night food Ajman` / `best cafeteria in ajman`
* **Cluster Keywords:** `late night food delivery ajman`, `hassan mathar sandwich`, `best juices and shakes in ajman`, `cheap food in ajman under 20 aed`

## Prompt Engineering Architecture
1. **Cluster & Keyword Mapper Prompt:** Identifies search intent (TOFU/MOFU/BOFU) and designs the internal linking architecture between cluster topics and conversion landing pages.
2. **Long-Form Pillar Generator Prompt:** Produces an exhaustive 1,200+ word authority pillar post with H1–H3 hierarchy, localized context, ASCII architectural diagrams, and FAQ schema integration.
3. **Geo-Targeted Cluster Post Prompt:** Generates high-conversion local landing articles with transparent pricing in AED and direct ordering steps.

## Primary Tools Used
* **LLM Engine:** Google Gemini / ChatGPT / Claude
* **SEO Strategy Inspiration:** Backlinko, Google Helpful Content Guidelines
* **Documentation & Delivery:** Markdown, GitHub
